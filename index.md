# Política de privacidad de Forge Publicador

**Responsable:** Enric Fernandez (persona física). **Contacto:** slotty.contact@gmail.com

Última actualización: 30-10-2026.

## Qué es esta aplicación
Herramienta de uso interno que prepara vídeos de historia medieval y los sube al canal de YouTube de sus titulares. Es una aplicación de escritorio. La usan únicamente los titulares del canal; no está abierta a terceros.

## Qué datos de YouTube y de Google usa
Solo con el consentimiento de la persona titular del canal, a través de OAuth, la aplicación accede a:

- Su canal, para subir vídeos, miniaturas y subtítulos propios (permisos youtube.upload y youtube.force-ssl).
- Las estadísticas de sus propios vídeos (YouTube Analytics, solo lectura).

## Qué datos se almacenan
- El token de acceso queda en un archivo local, en el equipo de la persona titular. No se envía a ningún servidor nuestro, no se comparte y no se vende.
- No recopilamos, almacenamos ni tratamos datos personales de espectadores ni de otros usuarios.

## Uso y cesión
Los datos obtenidos de las API de Google se usan solo para publicar y medir los vídeos del propio canal. No se ceden a terceros, no se usan para publicidad y no se emplean para entrenar modelos de IA.

## Servicios de API de YouTube y de Google
Esta aplicación usa los Servicios de API de YouTube. Al usarla aceptas los [Términos de servicio de YouTube](https://www.youtube.com/t/terms) y la [Política de privacidad de Google](https://policies.google.com/privacy).

## Revocar el acceso
Puedes retirar el acceso de la aplicación en cualquier momento en https://myaccount.google.com/permissions. Para borrar el token local basta con eliminar el archivo de token guardado en el equipo.

## Cambios
Si cambia esta política, se actualizará esta página y la fecha de arriba.
